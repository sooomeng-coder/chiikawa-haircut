# 그림 규격

모든 파일 공통
- **같은 크기의 정사각형** (권장 1024×1024)
- **배경 투명 PNG**
- 모든 그림을 **같은 위치·같은 크기**에 맞춰 그린다 (한 파일 위에 겹쳤을 때 딱 맞아야 함)

| 파일 | 내용 |
|---|---|
| `hair-full.png` | 털 많은 몸. **얼굴(눈·입·볼·눈물) 없이** |
| `hair-cut.png` | 털 다 자른 몸. **얼굴 없이** |
| `face-cry.png` | 울상 |
| `face-calm.png` | 진정 |
| `face-relief.png` | 안심 |
| `face-endure.png` | 꾹 참기 |
| `face-shock.png` | 깜짝 |
| `face-happy.png` | 쓰다듬어서 기분 좋음 |
| `face-done.png` | 완성, 활짝 웃음 |

얼굴 파일은 캔버스 전체 크기 그대로, 얼굴 부분만 그리고 나머지는 투명하게 둔다.

파일을 넣은 뒤 `js/config.js`에 경로를 적으면 임시 그림 대신 쓰인다. 일부 표정만 넣어도 되고, 없는 표정은 임시 표정이 나온다.
