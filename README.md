# 치이카와 머리 잘라주기

가위, 바리깡, 손으로 치이카와의 덥수룩한 털을 정리해 주는 웹 게임. 팬이 만든 비공식 게임.

## 놀이 방법
- **가위**: 좁게 조금씩, 사각사각
- **바리깡**: 넓게 한 번에, 위잉
- **손**: 쓰다듬으면 기분이 좋아져요 (털은 안 잘림)
- PC는 마우스를 올려서 움직이기만 해도 되고, 휴대폰은 손가락으로 문지른다. 키보드 1·2·3으로 도구 전환.
- 털을 다 자르면 자동으로 완성되고, `완성!` 버튼으로 언제든 끝낼 수 있다.

## 구조
번들러 없는 순수 HTML/CSS/JS. 빌드 과정 없음.

- `index.html`, `style.css`
- `js/config.js` — 실제 그림 경로. `null`이면 임시 그림을 쓴다
- `js/art.js` — 그림 불러오기, 임시 몸·표정·도구 아이콘
- `js/sound.js` — 효과음 (Web Audio 합성, 파일 없음)
- `js/game.js` — 털 지우기, 표정 전환, 털 파티클, 완성 판정
- `assets/` — 실제 그림. 규격은 `assets/README.md`

화면은 세 겹이다: 털 다 자른 몸(아래) → 털 많은 몸(도구로 지워지는 층) → 얼굴(위). 얼굴을 따로 두어 털 상태와 상관없이 표정을 바꾼다.

## 표정
| 이름 | 언제 |
|---|---|
| `cry` | 처음 (거의 안 잘랐을 때 기본) |
| `calm` | 30% 이상 잘랐을 때 기본 |
| `relief` | 70% 이상 잘랐을 때 기본 |
| `endure` | 가위·바리깡으로 털을 자르는 중 |
| `shock` | 바리깡이 켜지는 순간 |
| `happy` | 손으로 쓰다듬을 때 |
| `done` | 완성 |

## 로컬 실행
```
python3 -m http.server 8000
```
브라우저에서 http://localhost:8000

## 배포 (Cloudflare Pages)
Workers & Pages → Create → Pages → Connect to Git → 이 레포 선택.
Framework preset `None`, 빌드 명령 비움, 출력 디렉터리 `/`. 이후 `main`에 푸시하면 자동 배포된다.
